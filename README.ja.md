# ASCENT

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **[日本語](README.ja.md)** · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [Svenska](README.sv.md)

高所登山とアイスクライミングを始める人向けの Android アプリです。カリキュラムは標高で組み立ててあり、1 課クリアするたびに少しずつ上へ進みます。

コースの系統は二つ、いつでも切り替えられます。**高所登山**は 6 単元・68 課で、5,000 m の入門から 8,000 m まで、通しで 3,200 m から 8,848 m。**トレッキング**は 4 単元・21 課で、日帰りから長距離まで、200 m から 5,630 m。進度・バッジ・復習キューは系統ごとに独立しています。

現在のバージョンは v0.20.18（versionCode 125）。言語まわりの作業は v0.19.24 で一段落し、翻訳 9 言語が英語と 1 項目ずつ対応しています（10,554 / 10,554）。v0.20 はバッジの改版で、40 個の実績すべてが平面画像からリアルタイム 3D の実体バッジになり、実績アイコンも同じモデルから描き出しています（以前の AI イラストは廃止）。解除ダイアログも同じ描画系で、画面の左右から紙吹雪が飛びます。モデルは APK に同梱するため、パッケージは 21 MB から約 41 MB に増えました。v0.20.3 では古くからの不具合を一つ直しました。リストを途中までスクロールし、二次画面に入って戻ると先頭に跳んでいたのが、元の位置に留まるようになりました。v0.20.6–v0.20.7 でバッジの画質を既定で最大にしました。ブルームが細かくなり、初回フレームの遅さで誤って切られることもなくなり、低下は 2 段階、4x MSAA も（ドライバの対応を確認したうえで、失敗時は静かに戻す形で）入っています。

## インストール

いちばん簡単なのは [Releases](https://github.com/Solar-CV/AscentApp/releases) のビルド済み debug APK です。`v*` タグを push すると GitHub Actions がビルドして release に添付します。

- パッケージ名：`com.ascent.climb`
- 最低要件：Android 8.0（API 26）、**arm64-v8a のみ** —— 32 ビット専用機には入りません
- サイズ：約 41 MB（バッジモデルは非圧縮で 38 MB、パッケージ後は約 11 MB）
- 権限：ネットワークと接続状態。問題集の更新確認とフィードバック送信に使います。オフラインでも全機能が動き、同梱の問題集は常にそこにあります

APK を端末に移し、提供元不明のアプリのインストールを許可してからタップします。初回起動にログインは不要です。

## 中身

### ルート

ホーム画面はベースキャンプから上へ伸びる一本のルートで、標高ごとの単元に分かれています（登山 6、トレッキング 4）。横にスワイプしてページを送り、1 ページに 2 単元。課は直線的に解放され、一つ通せば次が開きます。ノードには星が付き、現在の課には「開始」のヒント、単元の最後の課は金色で示されます。

上部の二つのピルで系統を切り替えます。タップするとボトムシートが開き、切り替えると 1 ページ目に戻り、選択は記憶されます。

進度は数字として保存していません。完了した課から毎回計算し直すので、あとで標高カーブを調整しても、古いセーブは詰まらずに再計算されます。

### 問題集

正式問題 1,533 問に、自動挿入される復習用の複製 154 問を加えて、表示は合計 1,687 項目。問題数は標高とともに増えます。5,000 m の入門は 1 課あたり約 15 問、7,000 m の技術単元は 30 問、トレッキングは 8 問です。

出題形式は 8 種類：単一選択、複数選択、並べ替え、組み合わせ、穴埋め、計算、ホットスポット（画像上の位置をタップ）、シナリオ（一つの問題文に複数ステップで答える）。

課を終えると、そのまま間違えた問題のやり直しに入ります。そこで正解した分は加点され、残りは復習センターへ送られます。復習は 0・1・3・7・16・35 日の間隔反復。安全に関わる問題は重み付けされ、理解したことの確認がないと先へ進めません。

### ハンドブック

長文 35 本、各 4〜8 節。装備、技術、医学、健康、天気、気象、判断、決断、安全、リスク、雪崩救助に分類されています。ハンドブックは系統で絞り込まれ、雪と氷の記事は登山にだけ現れ、高所病・低体温・ナビゲーション・野営・リーダーシップは両方で共有されます。出典は公開の医学・技術資料、商業ガイド資料 3 点、そして中国語の登山書 7 冊の整理稿です。中国語書籍は製品上の取り決めにより書名を出さず、ガイド資料は出典を明記します。

### トレーニング・復習・マイページ

トレーニングは準備度のパーセントと目標峰の標高を出します。復習は今日が期限の問題と安全に関わる誤答を先に並べます。マイページにはヘッダー、現在の標高、能力の概観、バッジへの入口、アカウント欄、フィードバックの入口があります。右上の歯車で設定、アバターでプロフィールページへ。

プロフィールには解除済みのバッジだけが出ます。40 個すべてはバッジウォールに並び、未解除はグレーのプレビュー、隠し実績は「?」で表示されます。

バッジは本物の 3D モデルです。金属の枠、エナメル、レリーフ。プロフィールかウォールで解除済みのバッジをタップすると全画面で開き、ドラッグで回転、ピンチで約 5.5 倍まで拡大、2 本指で部分を平行移動、ダブルタップで元に戻り、手を離すと正面のまま静かに揺れます。アイコンもモデルそのものから描いているので、ウォールと 3D 表示は同じ物体です。40 個すべてにモデルが揃いました。手描きの図は、今後追加される実績用の控えとして残します。アプリのどこで解除しても、ダイアログに出るのは同じ 3D バッジで、明るい台座の上、画面の左右からリボンが飛び込みます。

### 設定

外観はシステムに従うか、ライト／ダークに固定できます。選択は保存され、ステータスバーの色も合わせて変わります。言語もシステム追従か手動指定で、切り替えると UI とコンテンツが同時に変わり、再起動は不要です。問題集の欄では現在のバージョンの確認、更新のチェック、同梱版への復元ができます。開発者モードは「このアプリについて」のバージョン番号の裏に隠れていて、7 回タップで開きます。

### フィードバック

マイページ → フィードバックと提案。アカウントカードの下、安全に関する注意書きの上にあります。種類（不具合／提案／内容の訂正）を選び、内容を書き、返信先のメールアドレスを任意で残し、診断情報を任意で添付します。送信は Formspree 経由でメンテナに直接届きます。通信できないときは同じ本文をメールで送る導線が出て、メールアプリが無ければ本文をクリップボードにコピーします。

診断情報は既定でオフ。内容はアプリのバージョン、Android のバージョン、端末の機種、表示言語、問題集のバージョン、現在の系統、進度の数字、直近の未捕捉例外です。課の本文、解答履歴、アカウント、クリップボードは含みません。

## 10 言語

UI の文言とコース内容は次の言語で提供しています。

简体中文（原文）、繁體中文、English、日本語、Deutsch、Français、Español、Italiano、Русский、Svenska

10 言語すべて揃っています。各言語が独自の入口層、課の要点、ハンドブック本文、問題集を持ち、キー集合は英語と 1 項目ずつ一致しています——**10,554 / 10,554**、欠け 0、重複 0、孤立キー 0。

| 層 | 項目数 | 翻訳 9 言語 |
|---|---|---|
| 入口（課・単元・ハンドブックの題・峰の名前） | 117 | 100% |
| 課の要点 | 443 | 100% |
| ハンドブック本文 | 378 | 100% |
| 問題集（問題文 / 選択肢 / 解説） | 9,422 | 100% |

用語は逐語訳ではなく、各言語の登山界の言い方に合わせています。スウェーデン語の stegjärn / isyxa / standplats、ドイツ語の Steigeisen / Pickel、ロシア語の кошки / ледоруб、イタリア語の corda fissa / bloccante / sosta など。医学的な用量、雪崩の等級、斜度、気温はそのまま移し、数字の書き方だけを言語慣習に合わせています。三つの流儀は意図的に分けています。

- 英語・中国語・日本語：`6.5 °C`、`5,000 m`
- ドイツ語・スペイン語・イタリア語：`6,5 °C`、`1.000 m`（小数点はカンマ、桁区切りはピリオド）
- フランス語・スウェーデン語：`6,5 °C`、`5 000 m`（小数点はカンマ、桁区切りは空白）

読み手への語り口も言語ごとに違います。ドイツ語は無人称の man 形式、スペイン語は tú、フランス語は vous、スウェーデン語とイタリア語は du / tu。一方、課の要点はどの言語でも無人称の文体です。

万一その言語に項目が無い場合の順序は、選択言語 → 英語 → 中国語原文。この経路はいまや保険でしかありません。

ここに書かれていることは医学的助言ではありません。薬や応急処置の判断は医師に相談してください。

登頂を約束するものでも、順応の結果を保証するものでもありません。

インストラクターが必要と記された課では、理論を終えた時点でその旨をはっきり伝えます。

## 自分でビルドする

ツールチェーンはすべてホームディレクトリに置けます。Homebrew も Android Studio も不要です。この環境で使っているのは次の通りです。

- `~/android-toolchain/jdk`：Temurin OpenJDK 17
- `~/android-toolchain/sdk`：Android SDK（platforms;android-34、build-tools;34.0.0、platform-tools）
- `~/android-toolchain/gradle-8.9`：Gradle 8.9

```bash
export JAVA_HOME="$HOME/android-toolchain/jdk/Contents/Home"
export PATH="$JAVA_HOME/bin:$PATH"
export ANDROID_HOME="$HOME/android-toolchain/sdk"

cd AscentApp
"$HOME/android-toolchain/gradle-8.9/bin/gradle" assembleDebug
```

Gradle 8.9 のラッパーも同梱しているので、Gradle の入っていない環境でも大丈夫です。

```bash
cd AscentApp
./gradlew assembleDebug
```

成果物は `app/build/outputs/apk/debug/app-debug.apk` に出ます。

## コンテンツを変える

既存の課に問題を足すなら `data/Expansion*.kt`。新しい課なら `data/NewLessons.kt` に `Lesson(...)` を書き、`Curriculum.kt` の該当単元に id を足します。順序と単元の所属は `Curriculum.kt` だけが持ちます。

そのあとチェックを走らせます。

```bash
bash tools/contentcheck/run.sh
python3 tools/i18ncheck.py
```

一つ目はアプリの内容を純 JVM のプロジェクトに同期し、本物の組み立てロジックを走らせて、問題数、難易度の推移、範囲外の答え、空の問題、解放ロジック、実績の定義を検査し、`bank/bank.json` と `bank/manifest.json` を書き出します。二つ目は 4 層のカバレッジを言語ごとに出し、キーの差分を取ります。どちらもエミュレータ不要です。

問題集を触ったら `data/bank/BankConfig.kt` の `BUNDLED_VERSION` を上げてください。上げないとクライアントは変わっていないと判断します。

## 問題集のオンライン更新

問題集は三層です。ローカルキャッシュ、同梱、オンライン差分。参照順はキャッシュ → 同梱で、オンラインのものはローカルより新しいときだけキャッシュを上書きします。

ですので、飛行機の中、電波の無い谷、落ちたサーバー、壊れた JSON、sha256 の不一致、古いバージョン。どれも現状維持で、学習には影響しません。更新は起動後に静かに確認し、前回から 6 時間以上経ち、URL が設定されているときだけ動きます。

新しい問題集を出すには：内容を変える → `BUNDLED_VERSION` を上げる → `contentcheck` を走らせる → `bank/bank.json` と `bank/manifest.json` をサーバーか CDN に置く → 次回起動で反映。リリースは不要です。

古いアプリが新しい問題集で壊れることはありません。`manifest.json` の `minAppVersion` が古すぎるクライアントを止め、未知のフィールドは無視され、壊れた問題はその 1 問だけ飛ばします。

## 最近の変更

**v0.20.18：エベレストの地形モデルを更新**

- 「Climbing Grand Slam」のモデルを細部中心に作り直しました。経幡の旗は 0.42 × 0.26 mm に拡大（以前はスマホでは見えませんでした）、紐は二段の石積みに載せ、旗ごとに雪面とのクリアランスを検証。小さな部品はシーン全体へのレイキャストではなく地形メッシュを直接サンプリングします
- アイコンは新しい hero レンダーから再生成。姿勢と構図は変更なし

**v0.20.17：誤って大きく回る問題を修正**

- ピンチ後に片方の指を離すと「一本指のドラッグ」として扱われ、基準点は二本指の中心のまま。その差でバッジが大きく飛び、その飛びが慣性に乗って回り続けていました。ジェスチャを状態機械に変更し、二本指の操作が始まったら残った指は無視、ピンチでは慣性も残しません
- 拡大中は自動の揺れを止め、正面へ戻るときも瞬間移動ではなく滑らかに回るようにしました

**v0.20.16：細部を拡大**

- ピンチは最大 1.25 倍までしか拡大できず、峰名や標高の小さな文字がスマホでは読めませんでした。5.5 倍まで拡大できます
- 二本指の間隔を保ったままドラッグすると視点が平行移動し、端の細部まで見られます。一本指はこれまでどおり回転です。ダブルタップで拡大と移動をまとめてリセット。バッジのタイトル下に短い操作案内も追加しました

**v0.20.15：40 個すべてのバッジが 3D に**

- 最後の 6 個が到着。八千米卒業（角帽）、最終試験（旗付き登頂メダル）、六区足跡（ランニングシューズのソール）、十四座八千米（14 座の 8,000m 峰を並べた 2.5:1 の横長パネル）、ツートラック（二本レールのトレイ）、フルルート（エベレストの地形ブロック。セットで唯一メダルではない品）
- バッジのアイコンはすべてモデル自身のレンダーになったので、手描きの控えは壁から消えました
- フルルートだけ姿勢が別：台座に立つ置物なので、平たいメダルの 90° 回転は使わず、銘板がレンズを向くよう Y 軸で回します。レンダーの背景も黒ではなくグレーなので、切り抜きもそのグレー基準です
- モデルは 34 → 40 個、パッケージは 39.4 → 40.6 MB

**v0.20.14：バッジをどこからでも開けるように**
