把 7 本扫描校对的纸质书 + 3 份我方内部资料，统一成一套**可检索、可溯源**的题库编写底座。

**内容策略：实体书为主，网络公开资料只做交叉核对。** 写题目时从这里取素材，而不是从网上找。

### 关于校对质量

扫描件经 macOS Vision + iLovePDF 双引擎 OCR、按坐标逐行比对、版面重建，再由人工看图复核：

- 65 条含剂量/温度/尺寸的关键数据行**全部与扫描件一致**
- 383 条「疑 Vision 有误」已全部图像复核；正文识别准确率很高
- 错误集中在**表格、图注、装饰性标题、竖排文字、跨栏混排**处

因此：
- **正文引用可信度高**，可直接作为出题依据
- **表格与图注需对照原图**；本库会把噪声页标记出来，主题汇编会自动跳过它们

## 三、命令

```bash
cd ~/AscentApp/knowledge

node tools/kb.mjs build                     # 重建 docs/ + catalog.json + topics/
node tools/kb.mjs stats                     # 覆盖度报告：哪些主题资料厚、哪些薄
node tools/kb.mjs search 法式 前齿            # 全文检索
node tools/kb.mjs search 地塞米松 --book 01   # 限定某本书
node tools/kb.mjs page 04 196               # 打印《高山探险》第 196 页原文
```

`page` 的书号可以用编号（`04`）或书名片段（`高山`）。

## 四、怎么用它出题

### 第 1 步：看主题汇编

`topics/` 下每个主题已经把所有书里的相关段落抽好了，**每段都带精确出处**：

```markdown
## 《高山探险》　（10 段）

**[《高山探险》p.196]**　头上脚下、面朝雪面的滑坠，是理想的制动姿势，
只需一手以自我制动式稳住冰镐镐头…此时，应翘起双脚，以防止冰爪插入雪面造成翻滚。
```

### 第 2 步：核对原文

拿不准的段落用 `page` 调出整页，或直接翻扫描件：

```bash
node tools/kb.mjs page 04 196
```

### 第 3 步：写成题目

按 `~/AscentApp/import/README.md` 的格式写进 `import/*.md`，**`来源：` 字段填的就是这里的出处**：

```markdown
1. 滑坠时最理想的制动姿势是？
   - 头下脚上、面朝雪面
   - 头上脚下、面朝雪面
   - 头上脚下、背朝雪面
   - 侧身横滑
   答案：B
   来源：《高山探险》p.196
   解析：头上脚下、面朝雪面是理想制动姿势；此时应翘起双脚，
   防止冰爪插入雪面造成翻滚。头下脚上时必须先把双腿调整回向下方向。
```

### 第 4 步：编译与发布

```bash
cd ~/AscentApp
node tools/qbank/build.mjs                  # 题目编译进 App
"$HOME/android-toolchain/gradle-8.9/bin/gradle" assembleDebug
bash tools/contentcheck/run.sh              # 校验 + 导出在线题库
```

### 调整抽取范围

改 `taxonomy.json` 里某个主题的 `keywords`，然后：

```bash
node tools/kb.mjs topics     # 只重建主题汇编，很快
```

> 实测有效：给 l5 把死词（`冰爪技术`、`前齿攀登`，命中 0）换成 `立齿`、`行走齿`、`脚踝` 后，
> 收录从 21 段升到 33 段，覆盖书数从 3 本增到 5 本。

## 六、维护

- 新扫描书校对完成后，把 `-校对版.md` 放进 `~/技能书/校对版/`，在 `tools/kb.mjs` 顶部的 `BOOKS` 数组里加一条，重跑 `build`
- 主题汇编里每本书最多收录 10 段；命中数超出时会按相关度排序取前 10
- `docs/` 里的 `<!-- noisy -->` 标记表示该页 OCR 噪声大（封面、目录、表格串行），主题汇编会自动跳过这些页
