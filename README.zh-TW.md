# ASCENT · 攀登之路

[English](README.md) · [简体中文](README.zh-CN.md) · **[繁體中文](README.zh-TW.md)** · [日本語](README.ja.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Русский](README.ru.md) · [Svenska](README.sv.md)

一個給高海拔攀登和攀冰新手做的 Android 應用。課程按海拔組織：每過一課，海拔往上走一段。

兩個課程大類可以自由切換：**高山攀登** 6 個單元、68 課，從 5,000 米入門排到 8,000 米，走完海拔從 3,200 m 到 8,848 m；**徒步** 4 個單元、21 課，從一日徒步排到長線，走完海拔從 200 m 到 5,630 m。兩條大類的進度、徽章與複習佇列各自獨立。

當前版本 v0.20.13（versionCode 120）。語言工程在 v0.19.24 收官——九種翻譯語言與英文逐條對齊（10,554 / 10,554）。v0.20 是徽章改版：34 枚成就從平面圖換成即時 3D 實體徽章，成就圖示也直接由模型渲染，舊的一批 AI 插畫已棄用。解鎖彈窗用同一套渲染並從螢幕兩側噴綵帶。模型隨包分發，包體從 21 MB 漲到約 39 MB。v0.20.3 順手修掉一個老毛病：列表滑到中間、進二級頁再退回來會彈回頂部，現在停在原處。v0.20.6–v0.20.7 把徽章畫質預設拉滿：泛光更細且不再被首幀的卡頓誤判關閉，降檔改兩段，並接上 4x MSAA（先查驅動能力，失敗靜默退回）。

## 裝到手機上

最省事是從 [Releases](https://github.com/Solar-CV/AscentApp/releases) 下預構建的 debug APK。推 `v*` 標籤時，GitHub Actions 會自動構建並附到 release 上。

- 包名：`com.ascent.climb`
- 最低系統：Android 8.0（API 26），**僅 arm64-v8a** —— 純 32 位機型裝不上
- 體積：約 39 MB（模型未壓縮 32 MB，打包後約 9 MB）
- 權限：聯網與網路狀態，用於檢查題庫更新和提交回饋。斷網時所有功能照常，內建題庫一直在

安裝沒什麼特別：把 APK 傳到手機，在系統設定裡允許安裝未知來源應用，點安裝。第一次開啟不需要登入。

## 裡面有什麼

### 路徑

主頁面是一條從大本營往上走的路線，按海拔分單元（攀登 6 個、徒步 4 個）。可以左右滑分頁，每頁兩個單元。課程線性解鎖，過一課開下一課。節點上會顯示星級，當前課有「開始」提示，單元最後一課用金色標出來。

頂部兩顆膠囊切換課程大類，點開是底部彈層；切換後自動回到第一頁，選擇會記住。

進度不是另外存一個數字，而是由「已完成課程」即時算出來的。這樣以後調整海拔曲線，舊存檔也會跟著重算。

### 題庫

1,533 道正式題，加上 154 道自動插入的複習副本，一共 1,687 條展示項。題量隨海拔遞增：5,000 米入門平均每課 15 題，7,000 米的技術單元平均 30 題，徒步單元 8 題。

題型八種：單選、多選、排序、配對、填空、計算、熱點題（在圖上點位置）、情景題（一道題幹裡分幾步作答）。

答完當課立刻進入錯題重做。答對的錯題加分，仍然錯的進複習中心。複習用間隔重複，間隔是 0、1、3、7、16、35 天。安全關鍵題加權，答錯後要求確認理解才能繼續。

### 技能書

35 篇長文，每篇 4 到 8 節，按裝備、技術、醫學、健康、天氣、氣象、決策、判斷、安全、風險、雪崩救援分類。技能書現在按課程大類過濾：冰雪技術篇只在攀登出現，高原病、失溫、導航、營地、領導力這些通用篇兩邊共享。內容來自公共醫學與技術資料、三份商業嚮導資料，以及 7 本中文登山書的整理稿。中文書的部分按產品約定不顯示出處，嚮導資料的部分標來源。

### 訓練、複習、我的

訓練頁給一個準備度百分比和目標峰海拔。複習頁把今天到期的題和安全關鍵錯題排在前面。「我的」頁有檔案標頭、當前海拔、能力概覽、徽章入口、帳號區和回饋入口。點右上角齒輪進設定，點頭像進個人主頁。

個人主頁只展示已經解鎖的徽章。全部 40 枚在「全部徽章」頁，未解鎖的顯示為灰度預覽，隱藏成就給一個「?」。

大多數已有真實 3D 模型——金屬外框、琺琅嵌件、浮雕山體。在成就測試區點任意徽章就能轉起來：拖動旋轉、雙指縮放，鬆手靜置時會在正面輕微擺動。這些成就的圖示也由模型正面渲染而來，所以牆上看到的和轉起來的是同一個東西，舊的一批 AI 插畫已棄用。剩下 6 枚還沒有模型，繼續用手繪圖示，點開時是透視傾斜的收藏卡片。全 App 任意入口解鎖成就，彈窗裡展示的都是同一套 3D 徽章，底下墊一塊淺色圓盤，同時從螢幕左右兩側噴出綵帶。

### 設定

外觀可以跟隨系統，也可以手動鎖淺色或深色，選擇會持久化，狀態列配色一起變。語言可以跟隨系統或手動指定，切換後介面和內容一起變，不需要重啟。題庫區能看當前版本、檢查更新、恢復內建題庫。開發者模式藏在關於頁的版本號後面，連點 7 次開啟。

### 回饋

「我的」頁 → 回饋與建議，位置在帳號卡下方、安全宣告上方。選一個類型（問題回饋 / 功能建議 / 內容糾錯），寫清楚情況，可以留個信箱等回覆，也可以選擇附帶診斷資訊。傳送直接投遞到維護者信箱（Formspree）；網路不通時會給出「改用郵件傳送」的退路，連郵件應用都沒有就把正文複製進剪貼簿。

診斷資訊預設關閉，內容包括應用版本、Android 版本、機型、介面語言、題庫版本、當前大類、進度數字與最近一次崩潰堆疊。不含課程內容、做題記錄、帳號和剪貼簿。

## 十種語言

介面文案和課程內容都提供這些語言：

簡體中文（原文）、繁體中文、English、日本語、Deutsch、Français、Español、Italiano、Русский、Svenska

介面文案和內容層都是 10 種語言齊全。九種翻譯語言各有自己的入口層、課程要點、技能書正文和題庫，鍵集合與英文逐條對齊——**10,554 / 10,554**，缺 0、重複 0、孤兒鍵 0。

| 層 | 條目 | 九種翻譯語言 |
|---|---|---|
| 入口（課程名 / 單元 / 技能書標題 / 山峰） | 117 | 100% |
| 課程要點 | 443 | 100% |
| 技能書正文 | 378 | 100% |
| 題庫（題幹 / 選項 / 解析） | 9,422 | 100% |

術語按各語言登山圈的通行說法走，不是逐字直譯：瑞典語用 stegjärn / isyxa / standplats，德語用 Steigeisen / Pickel，俄語用 кошки / ледоруб，義大利語用 corda fissa / bloccante / sosta。醫學劑量、雪崩等級、坡度、氣溫這些數字在翻譯中原樣保留，只按語言習慣換千位分隔符和小數點，三種寫法是刻意分開的：

- 英文、中文、日文：`6.5 °C`、`5,000 m`
- 德文、西文、意文：`6,5 °C`、`1.000 m`（小數逗號、千位點）
- 法文、瑞典文：`6,5 °C`、`5 000 m`（小數逗號、千位空格）

人稱口徑也各自不同：德文用無人稱 man-Form，西文用 tú，法文用 vous，瑞典文和意文用 du / tu，而課程要點在所有語言裡都是無人稱句。

條目萬一在所選語言裡缺失，回退順序是：當前語言 → 英文 → 中文原文。這條路徑現在只是兜底。

## 安全邊界

這個 App 只覆蓋理論和認知準備。冰雪、繩索、攀冰、救援這些實踐技能，必須由持證教練現場指導和評估。

內容不構成醫療建議。涉及藥物和急救的決定，要問醫生。

不承諾登頂，也不保證高海拔適應結果。

標了「需教練評估」的課程，學完理論後會明確提示還需要實操驗證。

## 自己構建

工具鏈可以全部裝在使用者目錄，不需要 Homebrew 或 Android Studio。本機現在用的是：

- `~/android-toolchain/jdk`：Temurin OpenJDK 17
- `~/android-toolchain/sdk`：Android SDK，platforms;android-34、build-tools;34.0.0、platform-tools
- `~/android-toolchain/gradle-8.9`：Gradle 8.9

```bash
export JAVA_HOME="$HOME/android-toolchain/jdk/Contents/Home"
export PATH="$JAVA_HOME/bin:$PATH"
export ANDROID_HOME="$HOME/android-toolchain/sdk"

cd AscentApp
"$HOME/android-toolchain/gradle-8.9/bin/gradle" assembleDebug
```

倉庫裡也帶了 Gradle Wrapper 8.9，本機沒裝 Gradle 也能直接用：

```bash
cd AscentApp
./gradlew assembleDebug
```

產物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 改內容

給已有課程加題，寫在 `data/Expansion*.kt`。加新課程，在 `data/NewLessons.kt` 裡寫 `Lesson(...)`，再把 id 加進 `Curriculum.kt` 對應單元。順序和單元歸屬只改 `Curriculum.kt`。

改完內容跑一次校驗：

```bash
bash tools/contentcheck/run.sh
python3 tools/i18ncheck.py
```

第一個指令碼把 App 的內容源同步進一個純 JVM 工程，跑真實裝配邏輯，檢查題量、難度遞增、答案越界、空題、解鎖邏輯和成就定義，然後匯出 `bank/bank.json` 與 `bank/manifest.json`。第二個逐語言統計四層覆蓋率，並做 key 差集。兩個都不用裝模擬器。

改動題庫後記得把 `data/bank/BankConfig.kt` 裡的 `BUNDLED_VERSION` 加一，否則客戶端會認為沒有新版本。

## 題庫線上更新

題庫有三層來源：本地快取、隨包內建、線上增量。實際取用順序是快取 → 內建；線上那份只在比本地新時才覆蓋快取。

所以飛機上、山裡沒訊號、服務端掛了、JSON 格式錯、sha256 不匹配、版本更舊，這些情況都只會保留現狀，不影響學習。啟動後靜默檢查更新，距上次檢查超過 6 小時、且已經配置地址才發請求。

釋出一份新題庫：改內容 → `BUNDLED_VERSION` 加一 → 跑 `contentcheck` → 把 `bank/bank.json` 和 `bank/manifest.json` 傳到伺服器或 CDN → 下次開啟 App 自動更新，不用發版。

舊版 App 不會被新題庫搞崩。`manifest.json` 裡的 `minAppVersion` 會攔住版本不夠的客戶端，未知欄位直接忽略，單條題目格式錯誤只跳過那一條。

## 最近改了什麼

**v0.20.13：徽章模型增至 34 枚**

- 新增六枚：6,000 米的學習、捲土重來、七天足跡、三週足跡、二十次跑課、安全第一（D 形主鎖）；`self_arrest` 換成新匯出的 v4
- 圖示去背補上「被外形圍住的背景」：卡扣中心孔、沖孔卡片的通孔以前是實心黑塊，現在能透出底色。逐塊判斷——與背景同色且整塊均勻才算孔，帶漸層的深色區域不動。包體 38.5 → 39.4 MB

**v0.20.11：3D 徽章展示頁的布光與背景**

- 展示頁原本只有兩盞燈，金屬只有一道弧面高光、浮雕偏平。現在拆成五盞方向光——主光、頂光、正面柔光、輪廓光與一點底部反彈光，總照度維持不變，層次變多但不會整體發白
- 另做了一張更暗的背景（合成波落日，重度模糊到只剩色場）以配合暗色主題。右上角膠囊在亮底 / 暗底之間切換，預設跟隨系統並記住選擇，只影響這一頁

**v0.20.8 – v0.20.10：開屏**

- 開屏改成黏土擬態：白底、邊緣收緊的圓盤、單峰山標；原本那句「學習進度 = 海拔」換成一句隨機的登山界名言（馬洛里、溫珀、繆爾、布克列夫、維斯特斯、田部井淳子、梅斯納爾、洛、博納蒂），約 1.7 秒後淡出，開啟「減少動態效果」時幾乎直接跳過。App 內其餘介面未改動 v0.20.9 起系統啟動畫面不再顯示任何圖示：啟動主題只用與開屏一致的底色，點開就是一片白（深色下近黑），緊接著圓盤落下. 每句都用他本人的原話原文，不做翻譯

**v0.20.6 – v0.20.7：徽章畫質**

- 泛光預設跑最高畫質：256 px、四層、MEDIUM。舊邏輯從第一幀就開始統計，著色器編譯的幾百毫秒足以把它一路判死，之後穩定 60 fps 也回不來。現在先跳過 2.5 秒預熱，閾值放寬到 50 ms（20 fps）並要連續三個視窗，降檔分成「完整 → 低配 → 關」三檔
- 4x MSAA 在驅動支援時預設開啟，建交換鏈前先查能力；一旦建鏈失敗就退回無 MSAA 並記住這次失敗，不會因為一個抗鋸齒參數讓徽章畫不出來

**v0.20.4 – v0.20.5：小修**

- 開發者模式在解鎖前完全不可見——設定頁整塊（含「未開啟 · 連點版本號 7 次」）對普通使用者不渲染。連點 7 次的計數器仍然有效，只是不再顯示還剩幾次
